# جَمعة — Jamaa
ألعاب جماعية عربية على التلفزيون: بدون كلام، سؤال وجواب، برا السالفة، اكذب صح، ارسم وخمّن.

- `index.html` — شاشة التلفزيون (تطبيق جَمعة على Android TV يفتح هذه الصفحة)
- `join.html` — صفحة الجوال: اللاعب يصوّر الباركود ويدخل اسمه
- `admin.html` — لوحة التحكم: الأقسام والأسئلة (تسجيل دخول بحساب صاحب اللعبة)
